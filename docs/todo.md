## 개선점 (소스 분석, 2026-11-12)

`src/` 전체(1,770줄)를 읽고 정리했습니다. 괄호 안은 근거 위치입니다. 위쪽 체크박스 중 이미 구현된 항목(트리, 편집, 자동 저장, 볼트 목록 등)은 아직 갱신하지 않았습니다.

### 높음: 데이터 손실·멈춤 가능

- [x] **저장 실패 시 무한 재시도**: 저장이 실패하면 `dirty` 가 남아 대기 시간이 0 이 되고, 매 루프마다 저장과 화면 그리기를 반복합니다. 파일이 잠겼거나 읽기 전용이면 CPU 를 계속 씁니다. 실패 후 재시도 간격을 둡니다. (`main.rs:566-581`)
- [x] **저장 실패 시 종료 불가**: `Ctrl+Q` 는 저장에 성공해야만 종료합니다. 저장이 계속 실패하면 앱을 닫을 수 없습니다. 한 번 더 누르면 저장 없이 종료하는 방법을 둡니다. (`main.rs:618-622`)
- [x] **외부 변경 덮어쓰기** (외부 수정 시각이 달라지면 자동 저장 멈춤, Ctrl+S 로 덮어쓰기, 편집 내용 유지): 노트를 연 뒤 Obsidian 이나 Google Drive 동기화가 파일을 바꿔도 확인하지 않고 자동 저장이 덮어씁니다. 저장 전에 수정 시각을 비교합니다. (`editor.rs:37-44`)
- [x] **원자적 저장 아님**: `fs::write` 로 바로 씁니다. 쓰는 중 종료되면 노트가 잘릴 수 있습니다. 임시 파일에 쓴 뒤 이름을 바꿉니다. (`editor.rs:41`)
- [x] **삭제 복구 불가** (`<목록 루트>/.trash/` 로 이동, 이름 충돌 시 `이름.<UTC 시각>.md`, 복구 UI 없음): `Ctrl+D` 는 파일을 바로 지웁니다. Obsidian 처럼 `.trash` 로 옮기는 방식을 검토합니다. (`files.rs:66`)

### 중간: 동작 오류

- [ ] **마우스 휠 스크롤이 되돌아감**: 휠로 `scroll_y` 를 바꿔도, 다음 그리기에서 커서가 보이도록 다시 맞춥니다. 커서가 화면 밖으로 나가는 만큼은 스크롤되지 않습니다. (`main.rs:674-684`, `ui.rs:305-310`)
- [ ] **목록 제목이 실제 폴더와 다름**: 목록 제목은 항상 볼트 경로를 보여 줍니다. `Ctrl+O` 로 하위 폴더나 볼트 밖 폴더를 열어도 제목이 그대로입니다. 목록 루트를 표시합니다. (`ui.rs:223`)
- [ ] **새 노트 위치가 새 폴더와 다름**: `Ctrl+N` 은 목록 루트에 만들고, `Ctrl+G` 는 선택한 폴더 안에 만듭니다. 기준을 맞춥니다. (`main.rs:211-213`, `main.rs:160-170`)
- [ ] **인자로 준 볼트가 설정에 영구 저장됨**: 실행 인자의 볼트는 항상 `config.toml` 에 추가되고, 앱 안에서 지울 방법이 없습니다. 임시 폴더로 한 번 실행해도 목록에 남습니다. 목록에서 제거하는 기능을 둡니다. (`vaults.rs:18-21`)
- [ ] **한글 입력 상태에서 글자 단축키 불가**: `r`(새로고침)과 삭제 확인 `y` 는 영문 글자만 받습니다. 한글 입력 상태에서는 `ㄱ`, `ㅛ` 가 들어와 동작하지 않습니다. (`main.rs:426`, `main.rs:289`)
- [ ] **이름 변경 입력줄 편집 불편**: 현재 이름이 확장자까지 채워지고 커서가 끝에 있습니다. 입력줄은 끝에 붙이기와 Backspace 만 됩니다. 확장자를 빼고 채우거나, 커서 이동과 전체 지우기를 넣습니다. (`main.rs:235-241`, `main.rs:126-148`)
- [ ] **폴더 이름 변경·삭제 없음**: `Ctrl+T`, `Ctrl+D` 는 파일만 받습니다. (`main.rs:226-233`)
- [ ] **Windows 예약 이름 미검사**: `CON`, `NUL`, 끝의 점·공백 같은 이름을 걸러내지 않습니다. (`files.rs:7-21`)
