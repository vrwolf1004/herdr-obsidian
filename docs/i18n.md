# 다국어 (i18n)

화면 문구는 `locales/<언어>.json` 에 `"키": "문구"` 로 들어 있습니다. `{이름}` 은 실행 중 값으로 바뀝니다.
구현은 `src/i18n.rs` 입니다 (herdr-talk 과 같은 방식).

## 지원 언어

| 코드 | 언어 | 상태 |
|------|------|------|
| en | English | 기준 (원문) |
| ko | 한국어 | 기준 (원문) |
| ru | Русский | **초안 (미검수)** |
| fr | Français | **초안 (미검수)** |
| es | Español | **초안 (미검수)** |
| de | Deutsch | **초안 (미검수)** |
| ja | 日本語 | **초안 (미검수)** |

`ru`, `fr`, `es`, `de`, `ja` 는 작성자가 초안으로 쓴 번역입니다. 원어민 검수를 받기 전까지 문구가 어색하거나 틀릴 수 있습니다.
각 파일의 `_meta.status` 값에도 같은 상태가 적혀 있습니다. 검수가 끝나면 그 값을 바꿔 주세요.

## 언어 선택 순서 (먼저 설정된 것이 적용)

1. 환경 변수 `HERDR_OBSIDIAN_LANG` (예: `en`, `ko`, `ja`)
2. 설정 파일 `config.toml` 의 `lang = "ko"`
3. OS 언어 (Windows 는 사용자 UI 언어)
4. `en`

지원하지 않는 값(예: `vi`)은 무시하고 다음 단계로 넘어갑니다. 값은 `ko_KR.UTF-8`, `ko-KR`, `KO` 처럼 써도 됩니다.

## 폴백

선택한 언어에 키가 없으면 `en`, 그래도 없으면 키 이름 자체를 보여 줍니다.
모든 언어 파일은 `en` 과 같은 키 집합을 가져야 합니다 (`_` 로 시작하는 `_meta.*` 제외). 테스트가 이를 검사합니다.

## 번역 규칙

- `{이름}` 자리표시자는 원문과 같은 이름으로 남겨야 합니다. 테스트가 검사합니다.
- 키 이름(`Ctrl+O`, `Enter`, `Esc` 등)은 번역하지 않습니다.
- 삭제 확인의 `y` 키는 언어와 무관하게 `y` 입니다.

## 새 문구 추가

1. `locales/en.json` 에 키와 영문을 추가합니다.
2. `locales/ko.json` 과 나머지 언어 파일에도 같은 키를 추가합니다 (영문을 임시로 넣어도 됩니다).
3. 코드에서 `t("키", &[("이름", 값)])` 로 씁니다.
