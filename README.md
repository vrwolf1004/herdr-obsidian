# herdr-obsidian

Browse, read, edit and search an [Obsidian](https://obsidian.md) vault inside a [herdr](https://herdr.dev) pane. Works with any Markdown folder, including folders synced by Google Drive for desktop.

> Status: in development. The features below are planned or partly built.

## Features (planned)

- Set a vault folder.
- Folder and note list in a side pane.
- Open a Markdown note by clicking it in the list.
- Edit notes; changes are saved automatically while you type.
- Search note text.
- A herdr tab for trying the plugin.

## Requirements

- herdr 0.9.0 or later
- Rust (stable), to build from source

## Build

```sh
cargo build --release
```

## Usage

```sh
herdr-obsidian --help
```
